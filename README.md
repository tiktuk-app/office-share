# משימה למשרד

מסך קטן שמופיע ברשימת השיתוף של אנדרואיד. משתפים מווטסאפ טקסט, צילומי מסך או תמונות, בוחרים לקוח ושומרים משימה באפליקציית המשרד.

- אין כאן שום פרטי לקוחות. רשימת הלקוחות נטענת מהשרת רק עם המפתח, והמפתח נשמר בטלפון בלבד.
- התמונות נשמרות בתיקיית "התכתבויות" של הלקוח בדרייב, והמשימה נכנסת ללשונית "משימות" באינדקס.
